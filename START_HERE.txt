⚡ RUNNING THE APPLICATION
═════════════════════════════════════════════

SETUP (One-time):
  1. Run: setup.bat (Windows) or ./setup.sh (Mac/Linux)
  2. This will install all dependencies

START SERVICES (Two terminals):

Terminal 1 - Backend API:
  $ cd backend
  $ python app.py
  
  Output: Flask running on http://localhost:5000

Terminal 2 - Frontend Web:
  $ cd frontend
  $ npm start
  
  Output: Browser opens at http://localhost:3000

TEST:
  • Visit http://localhost:3000
  • Paste code or upload file
  • Click "Analyze Code"
  • View results with confidence score

═════════════════════════════════════════════
🆘 TROUBLESHOOTING
═════════════════════════════════════════════

Backend won't start:
  → Check if port 5000 is free
  → Check Python is installed: python --version
  → Reinstall packages: pip install -r requirements.txt

Frontend won't load:
  → Check port 3000 is free
  → Check Node installed: node --version
  → Reinstall packages: npm install

Can't connect frontend to backend:
  → Check backend is running on port 5000
  → Check frontend .env has correct API_URL
  → Check CORS is enabled in Flask

Model loading error:
  → Ensure ml_pipeline/ directory exists
  → Run transformers installation:
    pip install transformers
